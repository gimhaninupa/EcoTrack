# � EcoTrack - Smart Waste Management System

A comprehensive waste management platform designed to connect residents, administrators, and service providers. Features dedicated portals for **Residents** and **Admins** to stream-line garbage collection, tracking, and issue resolution. Built with **React**, **TypeScript**, and **Firebase**.

---

## ✨ Features

*   **Dual-Portal System:** specialized interfaces for Residents (tracking, payments) and Admins (routes, analytics).
*   **🚚 Real-time Truck Tracking:** Live GPS tracking of garbage collection vehicles for residents.
*   **📱 Fully Responsive:** Optimized layout for Desktop, Tablet, and Mobile devices.
*   **📅 Smart Scheduling:** View upcoming collection schedules and route optimizations.
*   **� Payment Integration:** Secure handling of service fees and payment history viewing.
*   **🔔 Instant Notifications:** Real-time alerts for truck arrivals, delays, and service updates.
*   **📊 Admin Analytics:** Detailed dashboards for monitoring fleet performance and resident satisfaction.
*   **�️ Secure Authentication:** Role-based access control using Firebase Authentication.

## 🛠️ Tech Stack

*   **Frontend Framework:** React (TypeScript)
*   **Build Tool:** Vite
*   **Styling:** Tailwind CSS
*   **Backend & Auth:** Firebase (Firestore, Auth)
*   **State Management:** React Context API
*   **Routing:** React Router DOM
*   **Icons:** Lucide React
